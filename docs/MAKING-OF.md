# 製作紀錄：這個網站是 AI 做的

「跟川伯聊天」由 **dAAAb** 出題、看成果、做決定；程式、3D 模型、對話腳本、資料整理、上線設定，都是 Anthropic 的 **Claude** 做的（Claude Code 桌面版，模型 Claude Opus 5.5）。

## 人和 AI 怎麼分工

- **dAAAb**：提出點子、看成果、指出問題（漏字、太重的陰影、手機上點不到川伯、設定頁滑不到底…）、做所有需要判斷的決定（花錢的服務、網域、用詞、法律上的取捨），以及輸入密碼和驗證碼。
- **Claude**：研究 Portaly 上的政見與經歷並記下出處（[`research/NOTES.md`](../research/NOTES.md)），寫所有程式、3D 模型和對話腳本，部署與設定網域、資料庫、使用統計，並請另外的 AI 助手做內容、資安與授權審查，再依審查結果修正。
- 對話內容都依據公開資料整理；畫面上和分享出去的圖片都註明「模擬對話」與「粉絲創作・dAAAb 個人出資製作」。
